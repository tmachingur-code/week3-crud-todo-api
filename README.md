# Todo API (Express.js CRUD Project)

## Project Description
This is a simple RESTful Todo API built using Node.js and Express.js. It demonstrates CRUD operations, input validation, and filtering using in-memory data storage.

---

## Features
- Create a todo
- Read all todos
- Read single todo by ID
- Update todo (partial update)
- Delete todo
- Filter active todos
- Filter completed todos
- Input validation on create

---

## Technologies Used
- Node.js
- Express.js
